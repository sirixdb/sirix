# SirixDB Kotlin CLI

The CLI opens local Sirix databases. Run `sirix-cli --help` for commands and
command-specific help for options. `restore` restores a database backup; it is
separate from reverting a resource revision.

See the [agent quickstart](../../docs/AGENT_QUICKSTART.md) for JVM and JSONiq
as-of reads, diffs, whole-resource revert and cold reopen, and the
[REST quickstart](../../docs/QUICKSTART.md) for the server workflow.
