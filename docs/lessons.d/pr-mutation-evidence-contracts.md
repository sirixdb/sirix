<a id="mutation-evidence-contracts"></a>

- **Separate evidence, protocol and presentation.** Prove a report empty before promoting it to
  complete; recover append-only evidence record by record, including torn UTF-8. Aggregate debt
  over the report's declared scope. Classify a mutation by what consumes its value, and assert
  serialized contracts and literal subprocess behavior instead of implementation syntax. Cached
  outputs imply reuse only with matching task inputs. Preserve validation at every evidence
  consumer, including individual statuses through acceptance and accounting; an incomplete
  module's failure alone does not make an accepted label truthful. Default missing provenance
  to unproven, and preserve it when reloading serialized reports. Load selected targets with
  their completeness: a class emitting no mutant still belongs to the measured scope. Run
  completion is not loaded-evidence completeness: require every nonempty report/census component
  before judging absence, and retain saved failures even when their artifact is omitted. Resolve
  artifact paths before deduplication and grouping; spelling must not split one generated set.
  Enumerate rejection facts and completion-dependent claims together; cross every fact with every
  claim in behavioral tests, preserving partial-status verdicts as independent controls. Use first-parent history for
  branch windows. Merging coverage passes must preserve the union of source selections; apply
  source limits before that union. Keep bounded work inside its launcher's ownership and await
  cleanup before consuming output or starting new work. A worker's late identity receipt cannot
  establish ownership during startup; drop reuse when it defeats deadline enforcement. A flushing
  listener cannot preserve results blocked upstream: hold the first real analysis unit open and
  verify that later completed units reach disk before cancellation.
  Preserve the caller's interrupt signal when translating a cancelled wait into an unchecked
  failure. Deliver every module's coverage report to the analyzer; running its tests is only the
  producer half of that contract. Add new lessons as fragments so concurrent branches do not
  append to the shared file.
  Explicitly schedule new test tasks
  in CI; compilation alone supplies no regression protection. Evidence:
  [mutation reporter review](postmortems/pr-mutation-evidence-review.md).
