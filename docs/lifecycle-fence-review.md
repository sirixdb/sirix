# Lifecycle review fix handoff

R1: result closure must reach every owned producer before session teardown can close readers. The missing abstraction was close propagation across the axis composition tree and both descendant-expression iterator representations. Axis has a default close contract; composites forward it to every operand, and concurrent helpers close descendants on all exits. The JSON lazy iterator, cached descendant plans, JSON stream and XML stream forward closure. Cancellation preserves its primary failure and interruption.

R2: a failed node close must remain retryable until node ownership, including the shared write permit and commit scheduler, is released. Closing the node reader before the writer refusal had marked the transaction closed prematurely. The writer closes first, and session teardown retains failed open node transactions as well as unfinished writers. Real paused append workers now cover both continued refusal and worker exit between the node and page close attempts, in XML and JSON.

R3: session abort must discard a dirty successor after a terminal predecessor-hardening failure. Public rollback cannot reconstruct that poisoned epoch, and public close must retain its dirty-transaction guard. InternalNodeTrx.abort shares the close ownership boundary while permitting explicit discard; it fences scheduler termination after releasing the node lock. Earlier errors remain primary and later cleanup errors are suppressed. The hardening worker now closes its detached predecessor and clears the pending revision root on failure. Failed-hardening commit markers remain present so the next writer performs the existing recovery before reading pages.

Regression oracles:
- Real compiled descendant queries, for item input and real document items wrapped in Brackit ItemSequence at the expression input boundary, stop after one serialized result; every real ConcurrentAxis executor terminates before serializer close, while readers remain live until session close and are then closed.
- Nested concurrent producers terminate on explicit close and reset; composite cleanup attempts both operands despite a failure; helper failure retains the original exception and suppresses descendant cleanup failure.
- Real node transactions in two user sessions retain the writer permit after writer refusal. NodeTransactionAbortLifecycleTest pauses an actual append worker, injects the already-expired timeout state without a timed assertion, and checks worker exit and retry. Both continued page-close refusal and worker exit before the subsequent page close are covered for XML and JSON. The second user reads the original committed value, commits a new value, and reads it back.
- NodeTransactionAbortLifecycleTest also runs a real KEEP_OPEN_ASYNC_COMMIT intermediate commit in each format, mutates its successor while hardening is paused, and fails hardening. Session teardown must wait for the worker, retain the original cause, close predecessor and successor writers, clear the pending root, terminate the scheduler, and admit another writer. Separate tests preserve the public dirty-close guard.

Steady-state iteration loops were left unchanged. New loops are confined to close-time ownership cleanup. No budget bounds changed.
