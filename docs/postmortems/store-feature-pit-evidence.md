## PR description evidence

Independent binary fixtures cover required tags (including tags after incompat words), flags, versions and incompat words through ordinary, derived, standalone-tool and backup/restore paths. Focused tests and real PIT reruns cover the new classification and prior opening/compatibility guards. The remaining survivors/uncovered cases are individually cataloged below, including explicit legacy/API coverage limits and overlapping guards. Do not describe this as complete legacy-class mutation coverage.
